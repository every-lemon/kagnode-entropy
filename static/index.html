What this preview checks

Queue bounds, locking, request limits, identity binding and rekey separation are testable behavior. It runs as an ordinary process, without a hardware enclave. This does not establish a min-entropy estimate, NIST validation, physical memory erasure, impossible collisions or secrecy after full process compromise.

For ordinary application secrets, use the operating system’s random API directly. The intended security use of this project remains under review.
